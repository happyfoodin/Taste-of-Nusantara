Cara Menjalankan Website Taste Of Nusantara 

1. Clone repo tersebut, lalu masuk ke foldernya
   
   git clone https://github.com/happyfoodin/Taste-of-Nusantara.git
   cd Taste-of-Nusantara

2. Install terlebih dahulu
   npm install

3. Kemudian jalankan
   npm run dev

4. Buka link yang muncul di terminal 
   Nah biasanya link seperti ini "http://localhost:5173/"
